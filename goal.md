# NexusEngine 0.0.4 Showcase Goal

The Open Above must prove that a fresh product repository can consume one exact
NexusEngine candidate without private source or symlink assumptions.

Completion requires:

- clean locked installation of the exact Engine SHA;
- canonical Domain composition and unchanged authored gameplay;
- Web live/static Build success and browser validation;
- exact-hash MCP approval, repeated no-op, persistent receipt restoration, and
  runtime continuation after MCP disconnect;
- Android XR and PCVR package proof in their hosted environments;
- a clean committed branch ready for dependency-order integration.

Hardware execution, deployment, publication, and release-branch creation are
explicitly outside this repository goal.
